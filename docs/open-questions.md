# Open questions and research backlog

## Mechanism

- What makes an externally accessible capability reliably composable rather than merely advertised?
- Which dependency structures are truly necessary, and which reflect historical lock-in?
- When does a mandatory intermediary enable rather than restrict agency?
- How should migration feasibility be modeled separately from final-state quality?
- How do topology, authority, latency, and resource capacity interact in real deployments?

## Epistemology

- What observations distinguish missing graph edges from insufficient capacity or an invalid capability label?
- How should an agent choose what to observe when the observation itself changes the world?
- What constitutes evidence for changing a representation's coordinate system rather than its numerical parameters?
- Can an architecture learn reusable abstractions without assuming an unlimited search budget?

## Evaluation

- What set of scenarios is sufficiently representative for a robustness claim?
- How should immediate task performance be traded against recoverability and future reachable options?
- When does reconfiguration cease to pay for its transition costs?
- Can experiment protocols distinguish the effect of architecture from the effect of planning quality?

## Research hygiene

- Map overlapping concepts against MAPE-K / self-adaptive systems, graph reliability, hierarchical planning, control and viability, and causal inference.
- Prefer a smallest counterexample or executable baseline before expanding the theory.
- Track rejected hypotheses as well as successful demonstrations.
